# ゲーム1本目: 壁打ちPong

M7（[docs/02_ROADMAP.md](../../docs/02_ROADMAP.md)参照）で用意した、同梱1本目のサンプルゲーム。
DSL v0（[docs/03_DSL_SPEC.md](../../docs/03_DSL_SPEC.md)）のサブセットのみで書かれている
（配列・ループ・複合式を使わない、if/elseの入れ子とヘルパー変数だけで衝突判定を組んでいる）。

## 遊び方

1. `main.js` の中身を Web IDE（`apps/web`）の「コード」タブにコピー&ペースト。
2. 「ドット絵」タブで、タイル1番（パドル）とタイル2番（ボール）に好きな絵を描く。
3. 「ビルド&実行」を押す。上下キー（またはタッチパッド）でパドルを操作し、跳ね返るボールを打ち返し続ける。

## 実装メモ

- パドルの上下移動は画面外に出ないよう `if (paddleY > 2)` / `if (paddleY < 224)` でクランプしている。
- 衝突判定（ボールがパドルのY範囲内にいるか）は、DSLが複合式（`paddleY + 8`等）を扱えないため、
  毎フレーム `paddleBottom = paddleY; paddleBottom += 8;` を計算してから比較している。
- 「ANDで複数条件をまとめる」構文がないため、`if`の入れ子で論理ANDを表現している。
- ボールの進行方向は `ballGoingRight` / `ballGoingDown`（0か1のフラグ）で管理し、`if (flag) {...} else {...}` で分岐させている。
- 動作ロジックは `packages/dsl-compiler/src/games.test.ts` でこのファイルをそのままコンパイル・実行して検証している
  （パドルのクランプ、壁での跳ね返り、パドル衝突、ミス時のリセットをフレーム単位でアサート）。
