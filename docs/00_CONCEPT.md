# 00. コンセプト

## 背景

「ブラウザで NES エミュレータって作れないの？」という雑談から出発し、対話の中で以下の順に構想が固まった。

1. 純粋な NES エミュレータ自作は技術的には可能（jsnes 等の前例あり）。
2. ただし ROM を配布・note で公開するなら、既存の商用 ROM は使えない → **自作ゲームを同梱**する方針に。
3. 自作ゲームの開発手段として、当初は C言語（cc65）/ 6502アセンブラのルートを検討したが、
   「JS だけで完結するファミコン風エンジンを作る」方が読者ハードルが低いと気づく。
4. さらに踏み込み、「ROM バイナリを生成するツール自体も JS で作る」＝ **ブラウザ完結の自作アセンブラ/コンパイラ** という方向に振り切る。
5. 文法は「6502アセンブラ風」ではなく **「JS風の独自 DSL」** を採用（参入障壁を下げるため）。
6. 出力される `.nes` は本物の NES バイナリなので、**実機・他社エミュレータでも動く** → 配布・販売の実利と「本物を作った」感動の両方が手に入る。
7. NES エミュレータ本体の実装解説は連載の主役にしない。「動いて当然の舞台装置」として扱い、
   **主役は DSL コンパイラ・アセットエディタ・配布体験**に置く。
8. 音源もファミコン準拠（矩形波2ch+三角波+ノイズ）にし、専用トラッカー型エディタを用意。
   キャラクター/8bit画像素材も専用ピクセルエディタを用意し、JS風コードからシンボル名で参照できるようにする。
9. ストレッチゴールとして、WebRTC を使った NAT 超えのオンライン対戦（1コン/2コン）。

## プロジェクトの目的

ブラウザだけで完結する「ファミコン風ゲーム統合開発環境（Web IDE）」を作り、

- 自作の NES エミュレータ上ですぐに遊べて、
- JS 風 DSL で書いたロジックが本物の 6502 マシン語 ROM にコンパイルされ、
- ドット絵・チップチューンも同じツール内で作って `.nes` に埋め込め、
- 完成した `.nes` は実機やサードパーティエミュレータでも動作し、配布・販売もできる

というプラットフォームを構築し、その制作過程を note で連載記事として公開する。

## ゴール

- **G1**: Mapper 0（NROM）限定で完結する、動作する NES エミュレータ本体（CPU/PPU/APU）をブラウザ上に実装する。
  （達成後、[02_ROADMAP.md](02_ROADMAP.md) M10でMapper 0以外・PPUスクロール・サイクル駆動フルAPUまで拡張済み。
  現在の対応範囲・未対応項目は[04_EMULATOR_SPEC.md](04_EMULATOR_SPEC.md)参照）
- **G2**: JS 風 DSL → 6502 バイナリのコンパイラを実装し、`.nes`（iNESヘッダー + PRG-ROM + CHR-ROM）を生成できるようにする。
- **G3**: ドット絵（CHR-ROM）エディタと APU トラッカーを実装し、DSL コードからシンボル名で参照できるようにする。
- **G4**: 上記ツール一式を使って自作ゲームを 1〜2本完成させ、`.nes` として書き出し、実機互換の動作を確認する。
- **G5**: Web アプリ本体を GitHub Pages 等で公開し、note で連載記事として制作過程を発信する。
  （Create 側は [09_CREATE_PROJECT_MODEL.md](09_CREATE_PROJECT_MODEL.md) の公開判定を満たしてから。現状のタブ＋手書き紐づけは公開レベルに達していない。）
- **G6（ストレッチ）**: WebRTC を使った NAT 超えのオンライン対戦を実装する。

## 非機能要件

- **レスポンシブUI（マルチデバイス対応）**: PC・タブレット・スマートフォンいずれでも Web IDE・プレイ画面ともに利用可能なレスポンシブデザインとする。
  スマホからの「作る」「遊ぶ」「対戦に参加する」のすべてを想定する（詳細方針は [01_ARCHITECTURE.md](01_ARCHITECTURE.md) の「UI/UX方針」参照）。

## 非ゴール（当面やらないこと）

- 商用/既存 ROM の吸い出し・同梱・解析（著作権上、完全に対象外）。
- CPU 全命令・PPU サイクル精度など「フルスペック互換エミュレータ」を最初から目指すこと（必要な範囲から段階的に拡張する）。
- ~~MMC1 / MMC3 等の高機能マッパー対応（初期スコープは Mapper 0 のみ。将来検討）~~
  → [02_ROADMAP.md](02_ROADMAP.md) M10で対応済み（MMC1/UxROM/CNROM/MMC3/AxROMの5マッパー追加）。
  ただしVRC系・MMC5・Namco163等、まだ対応していないマッパーも多い（[04_EMULATOR_SPEC.md](04_EMULATOR_SPEC.md)参照）。
- DSL でフル ES 相当の文法（配列・オブジェクト・クロージャ・再帰など）をサポートすること（ゼロページ256バイト・浅いスタックというハード制約に合わせ、意図的にサブセットに絞る）。
- エミュレータ内部実装（CPU デコードやPPU同期の詳細）を連載記事の主役にすること。

## 成功の定義

- 読者が「環境構築ゼロで、ブラウザだけでファミコンゲームを作って公開できた」と実感できること。
- 生成した `.nes` が実際に他社エミュレータ（Mesen 等）や実機互換機（レトロフリーク等）で動作すること。
- 著作権的に完全にクリーンな状態で、note / BOOTH 等で恥ずかしくなく公開・販売できること。
