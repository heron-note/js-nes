# 07. コンテンツ運用計画（配布・販売）

> **方針転換（開発途中で決定）**: note連載は行わず、開発が完成してから一括で公開する（[02_ROADMAP.md](02_ROADMAP.md) 参照）。
> 本ドキュメント前半（ホスティング・ROM配布・収益化の仕組み）は完成後も引き続き有効な運用計画。
> 後半の「連載の章立て」は当時の検討過程として履歴保存している（現在は採用しない）。

## ホスティング & 配信の全体構成

- note自体にはHTML/JSを直接埋め込めないため、**Webアプリ本体は GitHub Pages 等の静的ホスティングに配置**する。
  現在 `https://heron-note.github.io/js-nes/` で公開中（`master` push時にGitHub Actionsで自動デプロイ）。
- note側には、キャッチーなプレイ画面のGIF/動画と解説記事を載せ、プレイ用リンク（または外部埋め込みカード）を貼る構成にする。

## ROMデータの持たせ方

- ファイル選択ダイアログでの手動読み込みに加え、自作ROMのバイナリを **Base64文字列としてJS内に同梱**しておくことで、
  「アクセスした瞬間、ワンクリックですぐ遊べる」状態を実現する。
- 加えて `.nes` ファイルそのもののダウンロード（`rom-builder`）、配布用スタンドアロンHTML（`apps/web` の「配布パッケージ」セクション）、
  カセットラベル風PNG画像の生成にも対応済み（M6完了）。

## 配布・収益化の出口

自分で作ったROMをどう届けるか、という「出口」を用意することで、単なる学習ツールから「クリエイター向けプラットフォーム」に育てる。

- **note / BOOTH / itch.io での配布**: 自作ゲームの `.nes` バイナリを有料記事やダウンロード商品として販売可能にする。
  購入者は、実機互換機（レトロフリーク、Analogue Pocket等）にSDカードで入れて実機プレイできるほか、自作ブラウザエミュレータへのドラッグ&ドロップでも遊べる。
- **配布用スタンドアロンHTML**: 「配布用HTMLを書き出す」ボタンで、自作エミュレータ（Web IDE本体）＋ゲームROMを1枚のHTMLにまとめて書き出せる（M6実装、ZIPではなく単一HTMLファイル形式を採用）。
  自分のポートフォリオサイトやGitHub Pagesに置くだけで、誰でも自分のゲームを単体Webゲームとして公開・収益化できる。

## 完成後の公開記事（連載ではなく単発）

連載はしないが、公開時に紹介記事は1本書く想定。以下は旧・連載構成の検討内容で、単発記事のネタ元として再利用する（履歴保存）。

### 第1回: JSを書いたらファミコンROMが焼けるWebツールを作った

- **目的**: ツールの存在を知らしめ、ワクワク感を最大化する。
- **見せ方**: 「ブラウザ上でJSを書くと、即座に画面内のファミコンで動きます。`.nes`の書き出しもできます」というデモGIF/動画を冒頭に配置。
- **CTA**: ツールへのリンク、次回予告（テンプレを改造して自分のゲームを作れること）。

### 第2回: 10分で作る、はじめてのファミコンゲーム

- **目的**: 読者が実際に手を動かして「自分でも作れた」という成功体験を得る。
- **見せ方**: 用意したテンプレートからドット絵を置き換え、十字キーでキャラを動かすまでの実践チュートリアル。
- **CTA**: 「あなたが作ったゲームをシェアしてください」という呼びかけ（シェア用URL機能、[02_ROADMAP.md](02_ROADMAP.md) M7で実装予定のためタイミングは要調整）。

### 第3回: ファミコンならではの「おいしい制約」のハック法

- **目的**: 技術好きの知的好奇心を刺激する「制約との付き合い方」を見せる。
- **見せ方**: スプライト制限・パレット制約をJS側からどう制御するか。ゼロページ枯渇警告などの「制約オーバー演出」（[02_ROADMAP.md](02_ROADMAP.md) 参照）も紹介。
- **CTA**: 応用編・カスタマイズの余地を示唆。

### 第4回: 完成したROMをカセット風に仕立てて世に放つ

- **目的**: 「本物のファミコンソフトを作った」感動をゴールとして提示し、配布・販売への導線を張る。
- **見せ方**: カセット画像生成、BOOTH/noteでの配布手順、実機や他社エミュレータ（Mesen等）での動作報告。
- **CTA**: 実際の配布リンク、販売ページへの誘導。

## お遊び要素の見せ場（記事内での使いどころ）

- 「自作ファミコンカセットのラベル風画像」（タイトル・作者名・ドット絵入り）の自動生成 → 第4回のハイライト。
- 「シェア用ワンクリックURL」（ソースコードをLZ圧縮しURLハッシュに埋め込み） → 第2回のCTAで活用。
- 「制約オーバー」の演出（ゼロページ枯渇、スプライト9個超過の警告バッジ） → 第3回のメインコンテンツ。
- CRTブラウン管風シェーダー（走査線・にじみのトグル）、電源投入時のグリッチ演出 → 優先度低、余力があれば第1回or第4回で軽く触れる程度。

## 著作権・コンプライアンス方針

- 同梱・配布するゲームは**すべて自作アセット・自作ROM**とし、既存の商用ROMや吸い出しデータは一切使用しない（[00_CONCEPT.md](00_CONCEPT.md) の非ゴール参照）。
- 開発時のCPU検証に使う `nestest.nes` 等の第三者テストROMは、開発ツール（`tools/`）内でのみ使用し、公開物・配布物には含めない。
