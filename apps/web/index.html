ビルド&実行

「パーツ」タブで作った各パーツ(ドット絵+振る舞い)と「シーン」タブで作った各シーン(パーツの配置+進行ロジック)を 全部combineして1本の.nesにコンパイルし、その結果がここ（左のプレビュー画面）で実行されます。 起動直後は動作確認用の内蔵スモークテストROM（emulator-core単体の疎通確認用、画面を単色で塗りつぶすだけ）を表示しています。 



              

                実際にコンパイルされた最終的なDSLソース（パーツ/シーンを結合し、playSound()を解決した後の姿）:
              

              

              
プロジェクトの保存/読込

              

                「パーツ」「シーン」タブでの編集内容は、ビルドするたびにブラウザ内(localStorage)へ
                自動保存され、次回このページを開いたときに自動で復元されます。
                別のPCへ移したり、バックアップを取りたい場合はJSONファイルとして書き出し/読み込みできます。
              

              

                
                
                
              


              
外部の.nesファイルを読み込む

              

                自作ROM以外に、Mapper 0/1/2/3/4/7対応の.nesファイル（ホームブリュー等、権利的に問題のないもの）を
                読み込んで動作確認できます。読み込むと左のプレビュー画面で実行されます。

パーツ

              

                ドット絵と振る舞い(プログラム)をセットにした「パーツ」を作ります。1つのパーツは
                シーン側で何個でもインスタンスとして配置でき、それぞれ独立した位置・状態を持てます
                （例: 同じ「敵」パーツを3体配置、等）。
              

              

                
                
                
                
              


              

                

                  
                  
                


                

                  

                    field 名前 = 初期値; でこのパーツのインスタンスごとの状態を宣言し、
                    behavior 名前(self) { ... } で振る舞いを書きます。
                    self.フィールド名で自分自身の状態を読み書きできます。仕様は
                    docs/03_DSL_SPEC.md を参照。
                  

                  
                

                

                  

                  

                    
                    
                  

                


                
ドット絵（このパーツ専用）

                

                  右の「タイルシート」にはこのパーツ専用のタイルを0〜255番まで256枚まで描けます。
                  behavior内のdrawSprite(id, x, y, tile, palette)のtileには
                  このパーツの中でのローカル番号（0起点）を指定します。他のパーツと番号が
                  重複していても構いません（ビルド時に自動でCHR-ROM全体の番号へ変換されます）。
                

                

                  

                    
                    

                  

                  

                    
タイルシート（クリックで選択・番号がdrawSpriteのtile引数）

                    
                    

                  

                

              

            

            

              
シーン

              

                パーツのインスタンスを配置し、進行ロジック（init/update）を書きます。
                instanceName.fieldで他のパーツのインスタンスの状態を読み書きでき、パーツをまたいだ
                当たり判定などはここに書きます（例: ball.y > paddle.y）。現在は1プロジェクトにつき
                シーンをちょうど1つだけ使えます。
              

              

                
                
                
                
              


              

                

                  
                  
                


                

                  

                    instance 名前: パーツ種別;でパーツを配置し、function init() {} /
                    function update() {}で進行ロジックを書きます。
                  

                  
                

                

                  

                  

                    
                    
                  

                

              

            

            

              
音源（APU）

              

                ドット絵パーツと同じように、音も「名前付きのアセット」として保存し、パーツ/シーンの
                コードから playSound(名前) として呼び出せます（ビルド時に自動で
                playTone(channel, noteIndex, duration) へ変換されます）。
                曲を打ち込むBGMトラッカーはまだ準備中（詳細はdocs/05_ASSET_EDITOR_SPEC.mdを参照）。
              


              
音を作る/試聴する

              

                「鳴らす」でその場で試聴できます（初回はブラウザの音声再生許可のため、一度クリックが必要です）。
                気に入ったら名前を付けて保存すると、コードから呼び出せるようになります。
