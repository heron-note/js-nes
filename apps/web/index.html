ビルド&実行

「コード」タブで書いたDSLと「ドット絵」タブのタイルをビルドすると、その結果がここ（左のプレビュー画面）で実行されます。 起動直後は動作確認用の内蔵スモークテストROM（emulator-core単体の疎通確認用、画面を単色で塗りつぶすだけ）を表示しています。

外部の.nesファイルを読み込む

自作ROM以外に、Mapper 0/1/2/3/4/7対応の.nesファイル（ホームブリュー等、権利的に問題のないもの）を 読み込んで動作確認できます。読み込むと左のプレビュー画面で実行されます。

配布パッケージ（M6）

「コード」タブでビルドすると、ここから配布用のカセットラベル画像やスタンドアロンHTMLを書き出せます。

ブロックエディタ（Scratch風）

プログラミング言語の文法を覚えなくても、ブロックを組み合わせるだけでゲームが作れます。 組み立てたブロックは「ビルド&実行」ボタンでJS風DSLのテキストに変換され（「コード」タブで中身を確認できます）、 そのまま本物の6502マシン語にコンパイルされます。

コードエディタ（JS風DSL・v0）

書いたコードは「ビルド&実行」ボタンで本物の6502マシン語にコンパイルされ、 そのまま画面プレビューで実行されます。仕様は docs/03_DSL_SPEC.md を参照。 


            

            

              
ドット絵エディタ（CHRタイル・8x8）

              

                右の「タイルシート」には0〜255番まで256枚の絵を別々に描けます
                （ファミコン実機のスプライト用パターンテーブルがそのまま持てる上限で、これ以上はMMC1等の
                「バンク切り替え」に対応した拡張マッパーが必要になります。本ツールはMapper 0のみ対応）。
                プレイヤー・敵・弾など、キャラクターごとに違う番号のタイルへ絵を描いてください
                （右下の数字が番号。クリックか、下の「タイル番号で移動」で切り替えて編集できます）。
                描いたタイルは「ビルド&実行」時にCHR-ROMへパッキングされ、
                drawSprite(id, x, y, tile, palette) の tile 番号として画面に表示されます。
                同じコード内で drawSprite(0, ..., 0, 0) と drawSprite(1, ..., 1, 1) のように
                id（画面上の何番目の表示枠か）・tile（どの絵を使うか）・
                palette（どの配色を使うか）を変えて複数回呼べば、複数のキャラクターを同時に画面へ出せます。
                下のパレットはあくまで編集時のプレビュー用で、実際の色は実行中のゲームコードが
                setSpritePalette()（スプライト用）/ setPalette()（背景用）で決めます。

音源（APU）

              

                DSLコードから playTone(channel, noteIndex, duration) を呼ぶと、
                効果音（SE）を鳴らせます（曲を打ち込むBGMトラッカーはまだ準備中。詳細は
                docs/05_ASSET_EDITOR_SPEC.md を参照）。
                下で音を試聴して、コード/ブロックに使うchannel・noteIndexの値を確認できます。
              


              
音を試してみる

              

                「鳴らす」を押すと、選んだチャンネル・音階で playTone() と同じ音がその場で再生されます
                （初回はブラウザの音声再生許可のため、一度クリックが必要です）。
              

              

                
                
                
              


              
実行中のチャンネル状態（モニタ）

              

                ゲーム実行中に playTone() が呼ばれると、下の4チャンネルの音量・周波数がリアルタイムに表示されます。
                サンプルコードでは A ボタン（キーボード: X、仮想パッドのAボタン）を押すと音が鳴ります。
